# MAPAS RUEMAG

Visualizador meteorológico desarrollado con Python y Streamlit.

## Ejecutar

Instala las dependencias con `python -m pip install -r requirements.txt` y ejecuta `python paginamapas.py`.

Los datos y recursos necesarios se configuran en la instalación local y no se incluyen en este repositorio. Configura la contraseña mediante `RUEMAG_PASSWORD` o los secretos de Streamlit. No publiques credenciales.
